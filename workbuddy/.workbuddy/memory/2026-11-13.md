## 追加修复：访问根路径先弹「服务未启动」502（11:41 重建 exe）

- 复现（隔离目录 + 真实 DB 副本 + 有效设备会话）：已登录 `GET /` → 502「影音播放器」，而 `/__auth/apps` 才是列表页。根因是入口把 `/` 当兜底转发给 `prefix='/'` 的后端，两个后端 6000/6002 都没启动就先弹 502，用户得手动敲列表地址。

- 新增配置项 `rootMode`（存 SQLite kv，管理端「系统配置 → 访问根路径 / 时」）：`portal`（默认，显示服务列表）/ `proxy`（旧行为，直接转发）。改完即时生效、重启保留。
- 同步清掉启动日志 / API 错误文案里残留的「改 config.json + 重启」提示（现在管理端在线改即时生效）。

## 追加：子路径部署（服务挂 /media）后端零改动适配（12:04 重建 exe）

用户现象：`/media/` 保留前缀 → 后端 404；去掉前缀 → 页面能开但样式全丢、`/favicon.ico` 502。根因是后端不知道自己在子路径下。

- 网关侧三类处理（`stripPrefix=true` 且 `prefix!=='/'` 时自动启用，无需新配置项）：
  1. `upstreamPath` 只在路径**确实带该前缀**时截断（否则 `/favicon.ico` 被切成 `/on.ico`——真 bug，已修）。
  2. HTML 注入 `<base href="/media/">`（修相对路径）+ 改写 `src/href/action/poster/srcset/url()` 里的 `/xxx` 绝对路径；CSS 改写 `url(/x)` 与 `@import "/x"`；后端 `Location: /login` 补前缀。改写时删 `accept-encoding` 拿明文；上游仍强压 gzip/br 或 HEAD/204/304 时跳过改写。
  3. 兜底：转发时下发 `gw_svc=<routeId>` cookie，页面里漏网的 `/assets/app.js`、`/api/state`、`/favicon.ico`、WS 按「最近访问的子路径服务」转发（该 cookie 不转发给后端）。
- `/media` → 302 `/media/`（否则相对路径解析到根上）。
- 管理端「转发服务」文案改为「去掉前缀 + 子路径适配」，列表列名同步；启动日志对「非根前缀 + 保留前缀」给出 404 预警。
- 验证：子路径专项 **27/27**、回归 **18/18**（挂在 `/` 的服务绝不被改写、二进制/JSON/gzip 原样透传、gw_svc 不外泄、502 友好页）、exe 冒烟 **15/15**。
- 经验：SEA exe 的 `ROOT = path.dirname(process.execPath)`，冒烟必须把 exe 一起复制到隔离目录，否则会操作真实 `dist/` 数据；且配置首次运行已迁入 `kv`，**DB 优先于 JSON**，副本测试要改 DB 而不是 JSON。

## 追加：改为「独立端口 + 服务根路径」架构（12:35 重建 exe）

用户决定按端口区分服务，彻底避开路径前缀改写。

- `routes` 表新增 `listenPort INTEGER DEFAULT 0`，含老库 `PRAGMA table_info` 检测 + `ALTER TABLE` 自动补列。
- `normalizeUpstreams()` 拆成两套：`listenPort>0` 的路由进 `PORT_ROUTES`（Map: port→route，强制 `prefix='/'`、`stripPrefix=false`，**不参与主端口路径匹配**）；其余仍进 `UPSTREAMS` 走路径前缀。
- 每个独立端口一个 `http.Server`，共用 `handleRequest`；用 `req.socket.localPort` 判断当前端口。`listeners: Map<port, server>` + `syncListeners()` 实现端口增删即时绑定/释放（`writeRoutes` 与启动时调用），EADDRINUSE 只告警不崩。
- 独立端口上：路径与查询串**原样**转发，零改写（`subpathOf` 不触发）；`__auth/*` 在每个端口都可用，会话 cookie 天然跨端口共享（cookie 不区分端口），未登录在 `/api` 返回 401 JSON、其余 302 到该端口的登录页。
- 门户 `appsPage(req)` 用 `reqOrigin(req)` 拼绝对地址 `http://host:<listenPort>/`；按端口探测后端置灰；502 页显示入口端口。管理端表单新增「对外端口」，表格「入口」列显示 `:70xx` + 独立端口标签。
- `validateRoute`：对外端口校验（1-65535、不能等于主端口、不能等于后端端口、不能重复分配）；`rootMode` 与老路径前缀模式全部保留兼容。
- 验证：多端口专项 **30/30**（根路径原样转发、无 base 注入、深路径+查询串、端口隔离、门户链接、未启动 502 与置灰、热加/热删端口、端口冲突校验、重启保持、跨端口共享登录态、cookie 不外泄）、回归 **14/14**（子路径改写、gw_svc 兜底、放行原地更新、配置页）、exe 冒烟 **12/12**（含老库自动补列）。

- 新模块 `auth-gateway/iploc.js`：加载 Buffer（SEA asset）或文件、二分查询、`normalize()` 归一化 `::ffff:` 与端口、内网/本机/保留地址直接给中文标签。性能 10 万次 54ms。

- 记录写入：`records` 表新增 `region` 列（老库启动自动 `ALTER TABLE`）；`addRecord` 统一兜底按 IP 算 region；历史记录（无 region）在 `GET api/records` 读取时现算补齐，**不回写数据库**、不污染 `recCache`。
