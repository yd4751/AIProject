## 网关：屏蔽微信登录，改为设备登录（机器码白名单）
- 需求：`网关先屏蔽微信登录，使用设备登录，自动获取机器码，未授权时提示`
- 实现（auth-gateway/）：
  - `config.json` 新增 `loginMode: "device"`（DEFAULTS 默认仍是 `wechat`，旧行为不受影响）；`decideMode()` 优先判定 device
  - `MODE === 'device'` 时 `WECHAT_PATHS`（/qr、/wxacode、/poll、/wx/callback、/mp-login）统一 403 `WECHAT_DISABLED`；`WECHAT_OK = MODE !== 'none' && MODE !== 'device'`
  - 新增 `device-login-page.js`：浏览器端持久设备 ID（cookie）+ 指纹 → POST `/__auth/device/login` → 服务端 `machineCode(id, fp)` 用 config secret 加盐生成机器码 → 查 `whitelist.devices`
  - 未授权：403 + `无权访问` + 机器码 + 复制按钮 + 自动轮询；同时写 `whitelist.devicePending` 与 records（带去重节流）；管理员放行后前端自动进入
  - 管理端新增「设备白名单」页（待授权/已授权、放行/停用/删除），授权记录里失败项也支持一键放行
  - 切回微信：`loginMode` 改 `wechat` 并重启网关
- 小程序示例 `pages/gate`：识别 `WECHAT_DISABLED`，提示改用浏览器做设备授权；设备模式下隐藏「重新验证」按钮
