# 2026-10-28

## 媒体播放器（E:/Project/workbuddy/media-player）
- 零依赖 Node 服务（server.js，127.0.0.1:5173）+ 原生前端（public/）。
- 功能：多格式音视频（文件/文件夹/拖拽/播放列表/媒体库）、0.25-4x 倍速、进度拖拽（悬停缩略图+缓冲条）、截图（视频帧/音频卡片+下载/复制）、全屏、6 套皮肤、豆瓣信息自动抓取。
- 豆瓣接口实测结论：`movie.douban.com/j/subject_suggest`（搜索）、`m.douban.com/rexxar/api/v2/movie/:id`（详情，需 iPhone UA+Referer）、`j/subject_abstract`（备选）可用；`api.douban.com v2` 的公共 apikey 已封；音乐 suggest 接口返回空（已做降级：ID3 标签 + 豆瓣音乐搜索外链）。
- 豆瓣图床有防盗链（直连 418），必须走服务端 `/api/img` 代理并带 Referer。
- `/api/stream` 支持 HTTP Range，本地大文件拖进度才流畅；`/api/browse` 做本地媒体库。
- 踩坑：CSS 自定义 display 会覆盖 `[hidden]`，需 `[hidden]{display:none!important}`；`setPointerCapture` 对合成事件抛错需 try/catch。
- 验证方式：无头 Chrome + CDP（MediaRecorder 现场生成 webm 测试视频）跑通全流程并截图确认。
- 修复 bug：`addFiles` 里对象简写误写 `file,`（应为 `file: f`），导致「打开文件」选任何媒体都抛 ReferenceError 且无任何反馈（媒体库路径不受影响才侥幸通过首轮测试）。已修复，并：addFiles 加 try/catch+toast、新增文件后总是自动跳转播放、`[hidden]{display:none!important}`。教训：file input 路径要用 CDP `DOM.setFileInputFiles` 真实验证，e2e 只测媒体库路径会漏掉它。
- 本轮修复 3 个问题：① 播放/暂停图标不切换 → 新增 `syncPlayUI()`（在 play/playing/pause/ended/loadstart 等事件与 loadEntry、初始化时调用），图标用 `#i-play`/#i-pause。② 音量条无填充 → `input[type=range]` 改用 `linear-gradient` + JS 写入 `--v`（0~1）表示填充比例，`paintRange()` 在 setVolume/setRate/volumechange 时调用；气泡内滑杆用 `--trk: var(--border)`。③ 音乐抓取无效。
- 豆瓣音乐可用方案（重要）：`music.douban.com/j/subject_suggest` 与 `m.douban.com/rexxar/api/v2/search` 都已失效（need_login/空）；可行的是 **搜索页 HTML 里内嵌的 `window.__DATA__`**（`search.douban.com/{movie|music}/subject_search?search_text=`，含 id/title/cover_url/rating/abstract），详情页 `m.douban.com/rexxar/api/v2/music/:id`（需 iPhone UA + Referer）字段齐全（singer/publisher/pubdate/genres/intro/songs）。建议接口 `j/subject_suggest` 仅作兜底。
- 排序经验：豆瓣搜索页常把再版/纪念版排前面，需靠打分纠正——主名完全命中 60 > 包含 30；原名命中加分要在「主名仅包含」时减半（否则「Abbey Road: Anniversary Edition」的原名 Abbey Road 会压过原版）；再叠加 log10(评价数) 的热度加分（上限 12）。
- 豆瓣搜索页有频率限制（`error_info: 搜索访问太频繁`，返回 items:[]），已做退避重试一次 + 空结果不写缓存 + 前端新增「重新匹配」按钮。
- 搜索结果区分影视/音乐：服务端 `/api/douban/lookup` 支持 `kind=all|movie|music` + `prefer`（音频→music、视频→movie，决定自动选中条目的类别；all 时两类各出 6 条）；前端搜索框下加「全部/影视/音乐」分段切换（状态存 localStorage `mp.dbkind`），候选按类型分组（`.cand-group` 标题 + 蓝色「影视」/粉色「音乐」tag），条目卡片 `dbSub` 前缀类型名，音乐/影视行字段按 kind 区分。坑：切换类型后若之前手动搜过，要调 runSearch() 刷新候选（autoFetch 不渲染候选会残留旧列表）；seg 按钮需 white-space:nowrap 防止文字换行。
