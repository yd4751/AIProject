## frptun 端口转发/内网穿透工具（从零实现）

用户需求：轻量稳定高负载端口转发工具，配置决定 C/S 角色；后续追加：Web 管理端+流量监控+IP/机器码黑白名单+SQLite 持久化；再追加：Windows/Linux 跨平台。

### 技术决策
- Go 单二进制，`role` 字段区分 server/client；零业务外部依赖。
- 控制信令与数据流分离；单端口复用：KindControl=0xC1 / KindData=0xD2 首字节区分，只开一个端口。
- 帧协议：1B kind + 4B 大端长度 + JSON（max 1MB）；数据连接头 8B connID。
- 高负载：每连接双 goroutine + sync.Pool(32KB) + CloseWrite 半关闭 + TCP_NODELAY/KeepAlive + 原子限流 + pending 超时 + 客户端指数退避抖动重连。
- SQLite 用 `modernc.org/sqlite`（纯 Go 无 CGO）。**关键坑**：最新版 v1.62 要求 Go>=1.26，本机 Go 1.23.1，必须用 v1.13.1。tidy 需 `GOSUMDB=off`（sum.golang.org 不可达会卡死）。
- 管理端 SSE 实时推送（非 WebSocket，更轻）；Basic Auth；前端纯 SVG 图表无 CDN；go:embed 内嵌页面保持单二进制。
- 机器码：hostname + 网卡 MAC 的 SHA256，跨平台无平台依赖。
- 交叉编译 `CGO_ENABLED=0 GOOS=linux/windows GOARCH=amd64/arm64` 全部成功。

## 追加：实时端口管理 + 管理端 UI 重做

用户需求：管理端实时新增/关闭端口；并吐槽原 UI 太丑、没布局。

### 设计
- 协议新增 MsgSyncServices（服务端下发权威映射列表）+ MsgServiceAck（客户端 ACK）；Message 增加 RequestID。AddPort 等待 ACK（3s 超时），保证"实时生效"可验证。
- store 新增 port_mappings（动态映射，UNIQUE(machine_id,remote_port)）与 disabled_ports（静态端口被实时关闭后的抑制项，防重连复活）。
- 服务端 clientConn.services 改为 map[string]*runningService，每个映射独立 context+listener，可单独 start/stop；register 时 computeDesired = 静态配置 + 动态(启用) - 禁用，全量对账；closeClient 必须真正 listener.Close()（context 取消无法打断 Accept，曾因此导致重连端口占用 bug）。
- RemovePort 会 stopService + closeTunnelsByService + dropPendingByService，真正断连释放端口。
- 客户端新增 runtimeSvc map，处理 sync_services 全量替换并 ACK；handleNewConn 优先查运行时表，回退静态配置（兼容旧服务端）。
- 管理端 API：GET/POST/DELETE /api/ports；SSE 快照加入 ports。

### UI 重做
- 从顶部 tab 平铺表改为侧边栏导航 + 顶栏 + 统计卡片 + SVG 柱状趋势 + LIVE 徽标的专业后台布局；新增端口管理页（新增表单 + 状态表格）。
- 纯 CSS/SVG/JS 无 CDN；go:embed 保持单二进制。
