## AI 额度池统一看板方案
- 需求：统一管理各 AI Agent 的积分/token 额度，限定个人自用、优先现成开源；要可视化每渠道剩余量与定时重置时间。
- 选型结论：订阅额度可视化用 OpenQuota（MIT / Tauri 2 / Windows / 完全本地 / 复用已有登录凭据 / Claude Code+Codex+Cursor+Copilot / Session+Weekly+重置时间）；Token 明细补 ccusage；API Key 额度用 new-api 做网关底座。
- 关键事实：Claude Code 的 statusline 脚本可直接拿到 `rate_limits.five_hour` 与 `rate_limits.seven_day`（含 `used_percentage`、`resets_at`），`/usage` 也可查；ccusage 只读本地日志算消耗，拿不到剩余额度与官方重置时间。
- 合规边界：订阅额度只做任务级派发（状态同步），不托管凭证、不代发请求；只有 API 额度可真池化。
- 产出：`quota-dashboard.html` —— 自包含看板原型，演示数据，9 个渠道，含实时重置倒计时、重置日程、7 日趋势、筛选；内联 JS 已通过语法校验。未接真实数据源。
