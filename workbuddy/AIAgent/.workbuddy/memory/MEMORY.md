## AI 额度池方案（2026-11-17 定调）
- 订阅类额度：只做逻辑池（状态同步 + 任务级派发），不托管凭证、不代发请求，规避 ToS 与风控红线。
- API 类额度：可真池化，用 new-api 做网关底座（渠道管理 + 配额 + 计费面板）。
- 可视化主力：OpenQuota（Windows 可用、本地运行、无遥测）；补充 ccusage 看 Token 明细。
- 调度核心设计：CU 归一化 + reserve/settle/release 账本 + 临期优先 FEFO + 会话亲和；网关只做原生路由，不做协议翻译。
