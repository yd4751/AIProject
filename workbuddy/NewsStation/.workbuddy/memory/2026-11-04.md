## 事件标签体系（用户提出事件需带地区/行业/类型）

- 采用四维可多值标签：region / industry / type / entity，统一存 `tags` 字典表 + `article_tags` + `event_tags`，不给 events 加列（多值、可切筛选维度）。
- 归一化是关键：US/United States/美国 → `region:us`；港澳台 `hk/mo/tw` 且 `parent=cn`，显示「中国香港/中国澳门/中国台湾」——口径写死。
- 抽取：四维词典合并做 Aho-Corasick 一次多模匹配；类型用组合模式（营收+净利润→earnings），不是单词匹配。
- 聚类打分改为 `0.7*cos(title) + 0.3*jaccard(tags)`，行业无交集直接不比。
- 标签用途：全局筛选条（URL 可分享）、点阵着色维度可切换、标签订阅（tag_filter JSON）、行业矩阵。
- 验收：地区 ≥90%、行业 ≥80%、类型 ≥75%（抽检 20 条）。
- PLAN.md 第 4/5/6/7/8/9 节已同步更新。

## 实体识别（NER）路线决定

- 事实澄清：中文 NER 在 Java(HanLP)/Python(LTP/HanLP2/THULAC/BERT) 成熟，缺的是 Go 实现；gse 只是分词，不做实体。
- 决定：M2 用词典法（500 高频实体），不上 Python sidecar（会废掉单 exe 交付），不上 ONNX（100MB+ 动态库）。
- 升级触发条件写死：抽检 20 条事件有 ≥3 条主实体缺失/标错 → 启用 LLM 增强通道，只跑热度前 50 事件、异步、结果缓存 origin=llm。
