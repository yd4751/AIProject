## M5 一键翻译（今日完成）
- 新增 `app/translate/`：`backends.py`（auto / mymemory / google_free / openai / libre / none 六种后端 + 自动回退链）、`service.py`（语言检测、缓存、失败降级、status）；`db.py` 加 `translations` 表（`UNIQUE(source_hash, target_lang)`）。
- **关键实测结论**：本机代理出口 IP 上 Google 4 个端点（gtx / dict-chrome-ex / clients5 / google.com）、MyMemory、Edge 匿名 token、Lingva、公共 LibreTranslate 全部 429/404/502；**MyMemory 直连（不走代理）正常**，英/日/法→中文均返回正确译文。故默认 `backend: auto` = 直连 MyMemory 优先、整批失败才回退代理 Google。MyMemory 固定直连，不受 `use_proxy` 影响。
- Web 接入：`routes.py` 注册 Jinja 全局 `tr_attr`（`@pass_context` + `Markup` + `html.escape`，只给外文打 `data-tr data-text data-zh`）；`_cards/index/event/subscriptions` 模板打标；`base.html` 加「一键翻译/显示原文」按钮；`app.js` 批量 POST + 回填 + localStorage 偏好；`app.css` 按钮样式。零新增依赖。
- 缓存策略：译文按文本 hash + 目标语言缓存；服务端渲染一次性读回全部 ok 译文注入 `data-zh`（避免 N+1）；失败写 1h 冷却；**后端未配置时不写失败缓存**，填好配置立刻生效。JS 用 `data-text` 作原文与请求 key，避免 DOM 文本与缓存 key 不一致。
- 接口：`POST /api/translate`（async + `asyncio.to_thread`）、`GET /api/translate/status`（后端链/缓存量）。
- 验证：`tests/test_translate.py` 新增 8 个测试（语言检测、缓存命中不调后端、失败降级+冷却、未配置不落缓存、auto 回退、OpenAI fenced JSON 解析、API 往返、模板只标外文）；全量 **42 passed**；`node --check app.js` 通过；`docs/PLAN.md` 已写回 M5 章节、目录结构、配置/接口表、已知限制与风险表。
- 已知限制：免费端点依赖公共服务匿名额度，额度耗尽时降级为「部分保持原文」不报错；要稳定高质量需填 `translate.openai.base_url/api_key` 或自建 LibreTranslate。
