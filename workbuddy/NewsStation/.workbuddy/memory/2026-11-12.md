## M9：打包成 exe，监听端口等配置走配置文件

**需求**：打包成 exe；监听端口等配置走配置文件。

**方案**：PyInstaller 6.22.3 单文件 exe + 「运行目录 / 程序目录」分离。新增 `app/runtime.py` 统一路径解析（源码模式 home=项目根；冻结态 home=exe 同目录，不可写时退回 `%APPDATA%/NewsStation`；`BUNDLE_DIR=sys._MEIPASS`）。config.yaml / sources.yaml / social_sources.yaml / data/news.db 全在 home，模板/静态/词典在 bundle；首次启动从内嵌种子复制三份 YAML 到 home，之后只认外部那份、不覆盖用户修改。home 下建同名目录可覆盖模板/静态/词典。环境变量 `NEWSSTATION_HOME` / `NEWSSTATION_CONFIG` 对应 CLI `--home` / `--config`。
